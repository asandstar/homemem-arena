# 第一关 · L1 餐桌整理入门（task-clean-table）

### 1. 基础操作与导航

- [ ] 首页 → 任务选择 → 点进 L1 → 简报页可滚动（1280×720 下标题、音量、开始任务、返回按钮全部可见）
- [ ] 点「开始任务」，第一视角生成能清晰看到餐桌方向或三套餐具，不被冰箱/柜子挡住
- [ ] 鼠标拖动可转视角左右/上下，Esc 可解除鼠标锁
- [ ] WASD 可在餐厅范围内移动，不穿视觉墙（撞墙即停），脚下没有奇怪空气墙
- [ ] V 键可切换第一 / 第三人称视角，切换后方向正确，不瞬移穿墙

### 2. 教学压力（回归要求：慢玩至少 3 分钟，记忆不红、chaos 不涨）

- [x] **自动化已验证**：Vitest 中模拟 L1 6 分钟 tickElapsed，chaos 被动增量 = 0，杯记忆未 outdated，未因 chaos 失败（见 threeLevelBackendSim.test.ts L1 regression 用例）
- [ ] 人工手持计时器在简报后慢玩 ≥3 分钟：中途故意不操作 / 反复打开菜单检查：
  - [ ] 左上 chaos 条始终停在低段（不跨黄/红段，不是一直上涨）
  - [ ] 左上已保存的记忆卡片不出现 OUTDATED 红叉或灰色褪色
  - [ ] 不因时间或 chaos 直接被判失败返回结果页
- [ ] 简报打开 / 教程弹窗 / 开场对话 / Esc 暂停菜单：打开期间倒计时/事件/记忆/chaos 全部冻结，关闭后从冻结处继续

### 3. 记忆 + 拾取门禁（Commit 1 要求）

- [x] **自动化已验证**：未按 E 保存记忆前不能拾取三件餐具（见 threeLevelBackendSim.test.ts L1 通关用例 `未按 E 前不能拾取任务物品` 断言）
- [ ] 实际靠近马克杯（或盘/叉），先不按 E，按 F 应提示"先记住位置"或同等提示，不能拿起
- [ ] 实际按 E 保存记忆，HUD 提示正确进入"可以拾取"状态，对应记忆卡片出现在记忆槽中
- [ ] 持有马克杯时，HUD 「F 放入」只能指向水槽（不能错误指向橱柜或桌面）
- [ ] 持有盘子/叉子时，HUD 「F 放入」只能指向橱柜（不能错误指向水槽）
- [ ] 按 HUD 提示的 F 放入后，系统判为正确放置，不给惩罚 + 目标打勾

### 4. 归位与完成

- [ ] 杯 → 水槽：物品放入后在水槽内可见，不漂浮、不嵌入水槽底、不穿模
- [ ] 盘 + 叉 → 橱柜：物品放入后在橱柜内可见，不漂浮、不飞出
- [ ] 三件全部归位后：左上进度逐项打勾，短暂横幅显示"目标完成"，**不出现阻塞弹窗/重复 Toast 抢鼠标锁**
- [ ] 关卡自动进入 Result 页（结果页）

# 第三关 · L3 过期的早餐记忆（task-breakfast，时间放宽至 360 秒）

### 1. 越阶段门禁（Commit 1 核心要求）

- [x] **自动化已验证**：g-encode-cereal-memory 完成前，pickEntity(bowl/cup/spoon) 全部返回 success=false，并带中文原因提示；完成编码后三件都可正常拾取（见 threeLevelBackendSim.test.ts L3 regression 用例）

- [ ] 开局阶段，HUD 的 E/F 提示全部优先服务"打开下层柜 → 记住麦片位置"这个未完成目标，不让附近的碗/杯/勺抢走提示

### 2. 编码麦片初始记忆（stage 1）

- [ ] 走到下层柜前可以按 F 打开柜门（有动画）
- [ ] 柜门打开后可以看到麦片盒（food/carton Kenney 模型）落在柜内合理位置，不漂浮、不穿模
- [ ] 对准麦片按 E 保存初始记忆，阶段推进"摆餐具"解锁

### 3. Distractor 摆餐具（bowl/cup → table）

- [ ] 现在碗/杯/勺都可以正常拾取了（F 提示出现）
- [ ] 持有碗/杯时，F 放入只指向餐桌；不会错误指向水槽或橱柜
- [ ] 碗/杯/勺放到餐桌后视觉正确落在桌面上：不漂浮、不嵌入、不穿模

### 4. 环境变化（麦片被钥匙猫搬走）

- [ ] 完成 distractor + 离开储物区后，会触发"厨房里好像有什么动静"提示（只有 cat sound / cabinet sound，**不直接告诉玩家麦片在哪里**）
- [x] **自动化已验证**：脚本事件将麦片从 lower cabinet 移到 upper cabinet，同时旧记忆 outdated

### 5. 冲突检测 + 记忆更新（核心 Aha Moment）

- [ ] HUD 只写"把麦片拿来放到餐桌"，不写麦片在哪个柜
- [ ] 玩家去下层柜，打开后看到"空" → 触发 toast："⚠️ 麦片不在这里了……你之前的位置记忆可能已经失效"
- [ ] 不被下层柜挡住：上层柜麦片必须在旧位置附近、沿同一面墙布置（视觉找得到但不自动蹦出来）
- [ ] 打开上层柜看到麦片（carton 模型在上层柜内合理位置）
- [ ] 玩家主动按 E 更新麦片记忆 → 麦片记忆从 "OUTDATED 下层" 翻成 "UPDATED 上层"，memoryUpdateCount ≥ 1（可在结果页 Session 数据中核对）

### 6. 最终完成与 Result

- [ ] 拾取麦片 → 放到餐桌
- [ ] 碗与杯清理到水槽（勺保留在桌上）
- [ ] 左上逐项打勾，360s 倒计时（不是 240s），目标完成横幅，不弹阻塞弹窗不抢鼠标锁
- [ ] 全部完成 → 自动进入 Probe → 最终 Result Page（比赛三关收口终点）
