# HomeMem Arena · 房间布局重设计方案

> 版本：R3 草案 · 适用 A1.5 Compact Hub Layout（120.81㎡, 5 房间）
> 坐标系：除特别说明，所有 `position` 均为**房间局部坐标**（相对 `sharedRooms[roomId].center`）。
> 旋转约定：`0 = 面向 +Z`，`π = 面向 -Z`，`π/2 = 面向 +X`，`-π/2 = 面向 -X`。
> Y 约定：落地家具 `y=0`；台上物品 `y = 支撑面高度`；墙饰 `y = 墙面挂载高度`（`collisionMode='none'`）。

---

## 一、设计原则

1. **贴墙放置，不悬空**：所有落地家具的某个面贴近一面墙（间隙 ≤ 0.1m）；台上物品必须落在支撑面 AABB 之内；墙饰必须明确挂在墙面（`collisionMode='none'`）。
2. **家具朝向符合现实逻辑**：沙发面向电视、餐椅面向餐桌、电视柜面板朝向观看位、床头柜柜门朝向床外侧。
3. **动线合理（门洞不被堵住）**：门洞开口两侧 0.5m 范围内禁止放置任何带碰撞的家具；房间主通道宽度 ≥ 0.8m。
4. **视觉密度适中**：每房间 5–8 件落地家具（餐厨为复合房间可放宽到 10–12），辅以 2–3 件墙饰；避免空旷与拥挤。
5. **单一数据源**：`decor-bed` 是床的唯一视觉所有者，禁止再由 task-container 重复渲染同一张床；地毯、餐桌、垃圾桶、洗衣篮等同样遵循"一物一所有者"。
6. **不重叠、不越界**：家具 AABB 之间不发生相交；所有家具落在所属房间 AABB 之内。

## 四、门洞与动线设计

### 4.1 门洞位置对齐验证

每对共享门洞在世界坐标系下中心点必须重合（误差 0）：

| 门洞 | A 房间 offset → 世界 | B 房间 offset → 世界 | 对齐 |
|------|---------------------|---------------------|------|
| living ↔ bedroom | living(-3.25,0)+(−3.25,0)=(−6.5? ) ⚠️ 见注 | bedroom(-5.65,0)+(2.4,0)=(−3.25,0) | 见注 |

### 4.3 玩家行走动线分析

```
卧室 ──(西门)── 客厅 ──(北门)── 餐厨 ──(东门)── 洗衣房
                  │
                (东门)
                  │
                 玄关
```

- **客厅枢纽横穿动线**（西门↔东门）：沿 `z≈0` 东西向横穿，宽度由沙发(z≥0.375)与北墙家具(z≤-1.9)让出，净宽 ≥1.9m。✅
- **客厅↔餐厨动线**（北门）：沿 `x=0` 南北向，沙发已偏离 x=0（x=-1.5），茶几虽居中但 `collisionMode` 走 task-container 且 footprint 较小，南北净宽 ≥2.4m。✅
