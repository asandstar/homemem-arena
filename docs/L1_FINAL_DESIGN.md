# L1 FINAL DESIGN — ENCODE 入门

> 状态：CURRENT / AUTHORITATIVE
>
> 对应实现：`src/data/tasks/clean-table.ts`

## 目标

让第一次进入游戏的玩家完成一条最简单、真正影响通关的记忆：靠近任意任务餐具按 E 保存位置，然后练习 F 拾取与归位。

## 配置

- 任务：`task-clean-table` / 餐桌整理入门
- 房间：`dining`
- 时限：无
- 物品：`obj-mug-1`、`obj-plate-1`、`obj-fork-1`
- 目标容器：马克杯 → `cnt-sink`；盘子、叉子 → `cnt-cabinet`
- 无隐藏物品、无环境变化、无猫干扰

## 阶段与硬门槛

| 阶段 | 玩家目标 | 完成条件 |
|---|---|---|
| `stage-learn-first-memory` | 对任意任务餐具按 E | 存在一条未过期的任务餐具记忆 |
| `stage-put-away-three-items` | 用 F 拾取并归位三件餐具 | 三件物品均在正确容器 |

第一阶段中拾取任务物品必须失败，并提示“先靠近任意餐具按 E”。因此记忆不是可跳过的教学文案。

## 目标反馈

- `g-save-first-memory`
- `g-mug-1-sink`
- `g-plate-1-cabinet`
- `g-fork-1-cabinet`

后三个目标依赖第一条记忆；每个目标完成时都显示横幅并在任务清单打勾。

## 文案边界

- 明确顺序：先 E，后 F。
- 只介绍 3 件物品和两个归位区域。
- 不出现抽屉、九件餐具、洗碗机、垃圾桶或限时压力。
- 结尾预告 L2：三件物品分散到三个房间，需要建立稳定空间地图。

## 验收

1. 未保存记忆时不能拾取任务餐具。
2. 保存任意一条任务餐具记忆后进入第二阶段。
3. 三件物品全部正确归位后通关。
4. 玩家可看见 0/4 → 4/4 的逐项完成反馈。
