# 当前公开三关设计（权威入口）

> 状态：CURRENT / AUTHORITATIVE
>
> 更新：2026-08-08

> 公开范围：`task-clean-table` → `task-leave-home` → `task-laundry-sort`

本文是当前公开版关卡设计的唯一文档入口。实现事实最终以
`src/data/tasks/clean-table.ts`、`leave-home.ts`、`laundry-sort.ts` 为准；历史规划、审计报告和截图不覆盖本文。

详细规格：[L1](../L1_FINAL_DESIGN.md) · [L2](../L2_FINAL_DESIGN.md) · [L3](../L3_FINAL_DESIGN.md)

## 1. 核心能力阶梯

| 关卡 | 能力 | 玩家必须使用记忆的方式 | 房间 / 物品 | 时限 |
|---|---|---|---|---:|
| L1 · 餐桌整理入门 | ENCODE 入门 | 对任意任务餐具按 E 保存第一条记忆，否则不能拾取 | dining / 3 件 | 无 |
| L2 · 钥匙猫的稳定记忆考验 | RECALL 稳定回忆 | 在 3 个房间分别保存书、马克杯、收音机的位置，全部编码后才能取回 | living、bedroom、entrance / 3 件 | 360s |
| L3 · 过期的早餐记忆 | UPDATE 记忆更新 | 保存麦片旧位置，发现现实冲突，再按 E 更新同一条记忆 | dining / 4 件 | 600s |

递进关系不是“物品越来越多”，而是记忆判断越来越复杂：

```text
L1：我会不会保存一条记忆？
  ↓
L2：环境稳定时，我能否依靠多条有效记忆完成跨房间任务？
  ↓
L3：环境变化时，我能否发现旧记忆失效并主动更新？
```

## 2. L1 Golden Path：第一次 ENCODE

1. 在餐厨出生，看到马克杯、盘子、叉子。
2. 靠近任意一件按 E，完成 `g-save-first-memory`。
3. 进入整理阶段；此前 F 拾取任务物品会被拒绝并给出明确提示。
4. 马克杯放入 `cnt-sink`；盘子、叉子放入 `cnt-cabinet`。
5. 四个目标逐项打勾，三件归位后通关。

设计边界：单房间、3 件可见物品、无时限、无环境干扰。L1 只教学“保存、拾取、放置”，不制造搜索压力。

## 3. L2 Golden Path：稳定 RECALL

1. 巡查客厅、卧室、玄关。
2. 分别靠近书、马克杯、收音机按 E，建立三条空间记忆。
3. 三条记忆全部建立后，阶段切换到 RECALL；此前拾取任务物品会被拒绝。
4. 依靠仍然有效的记忆，把三件物品送到客厅茶几。
5. 钥匙猫只产生声音和脚印，不移动物品、不把记忆标成过期。

设计边界：L2 必须让玩家学会“稳定环境中应相信有效记忆”。不得加入真实位移，否则会和 L3 的 UPDATE 教学冲突。

## 4. L3 Golden Path：过期记忆 UPDATE

1. 在北墙早餐备餐台看见麦片、碗和杯子，靠近麦片按 E 保存旧位置。
2. 把碗和杯子摆上餐桌；勺子已在桌上，形成短暂的注意力转移。
3. 脚本把麦片移动到附近的开放置物架，并把旧记忆标红。
4. 玩家回到早餐备餐台，发现“记忆中的位置为空”，完成冲突核对。
5. 玩家找到开放架上的麦片，按 E 更新同一条记忆，再按 F 把麦片送到餐桌完成关卡。

设计边界：所有任务物品必须真实可见、可拾取；静态 GLB 只作为台面或开放架使用，不把没有开门动画的柜体包装成可开柜。确认旧位置冲突后可以引导玩家观察开放架，本关考核的是判断并更新记忆，不是像素级找物。保留历史路由 ID `task-laundry-sort`，但公开内容已经是早餐 UPDATE 关。不得恢复衣物分类或袜子幽灵任务。

## 5. 统一交互与反馈约束

- WASD 移动，鼠标控制视角，E 保存/更新记忆，F 拾取/放置/交互。
- 第一次 Esc 释放浏览器鼠标锁；第二次 Esc 才打开暂停菜单。
- 目标完成后立即显示横幅，并在任务清单中打勾。
- 可交互与不可交互门框必须有可辨识状态；门、视角与小地图方向使用同一世界坐标约定。
- L1 无时限；L2 360 秒；L3 600 秒。时间只用于保持节奏，不应压过记忆教学。
- 模型轻微漂浮或穿插属于视觉 polish；只要不影响识别、接近、交互和通关，不阻断当前主流程。
