## §2. 唯一推荐

### 推荐 A1.5 (120.81 ㎡ Compact Hub)

**理由汇总 (Top 5):**

1. **家庭亲密感最优** — 房间尺寸落在真实 3 房公寓区间，怀旧科幻美术氛围能落地
2. **L1 教学 / L2 旗舰 / L3 挑战 三线都合适** — CARRY_ONE 机制下楼路线长度刚刚好 (既不无聊也不疲劳)
3. **手机性能风险低** — 比赛评审很可能用手机打开 GitHub Pages，A1.5 比 A1 少 18% 顶点
4. **无意义装饰填充风险低** — A1 需要 +60 件装饰物 (美术负担)，A1.5 只需 ~30 件 (Kenney 资产覆盖)
5. **未来调整余量适中** — 每房 ±0.3m 可调，发现问题不至于全部重做

## §3. 为什么 NOT A1 / NOT A2

### NOT A1 (148㎡):
- 🔴 **比赛手机性能 BLOCKER** (低端安卓掉帧风险高)
- 🔴 **108㎡ 空白填充 = 美术负担** (每个植物挂画地毯都要资产 + 碰撞 + 测试)
- 🟡 **L2 玩家走路超时** — L2 180s 内来回 24m + 保存记忆 + 找 key，可能超时率 > 40%
- 🟡 **Minimap 手机端 label 重叠**

### NOT A2 (104㎡):
- 🟡 **Entrance 前门 swing 净空 = 1.1m (边界通过)** — 雨伞 (height 0.8m) 视觉上会擦门
- 🟡 **Laundry 14.4㎡ = L3 搜索区只剩 4㎡** — 9 件衣服铺不开，袜子幽灵恶作剧一挪就找到 (无挑战)
- 🟡 **L1 教学路线过短** — CARRY_ONE 三次往返合计 < 10m，玩家没机会体会"为什么要 E 保存记忆"
- 🟡 **L2 搜索距离 = 4.2m 一眼看完** — stale memory 冲击力不足 (应该"扫两眼才发现"而不是"进门就看见")
- 🟡 **未来调整空间小** — 紧边界，只能放大不能缩小
