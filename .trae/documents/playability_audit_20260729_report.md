# HomeMem Arena 可玩性诊断报告
## 生成时间：2026-07-29
### 审计范围：3 个公开关卡（初次整理 / 出门大作战 / 洗衣幽灵）
### 审计方式：浏览器自动化试玩 + e2eTestApi 数据采集 + 6 维度评估（上手门槛、操作反馈、目标清晰度、压力与奖励循环、事件与叙事、完整体验收尾）
### 严重等级说明：P0 = 直接导致玩家玩不下去；P1 = 严重损害体验但关卡尚可通关；P2 = 体验瑕疵，影响长期留存

---

## 🚨 总览结论

**项目当前可玩性评分（满分 10）：3.5 / 10**
- **主因：反馈系统严重失效 + 操作压力与奖励完全不成比例 + 核心机制（记忆过期）没有实际体验感。**
- 对新手玩家来说："做对 / 做错的数值差异太小，视觉反馈太隐晦，时间又紧，根本学不会。"
- **有 3 个 P0 级问题，任何一个都足以让真实玩家在首次游玩 60 秒内流失。**

## 📊 问题清单（按严重度排序）

### 🏷️ P0-1｜L1 错放物品居然还加 100 分！奖励/惩罚系统完全失真
- **证据**：
  - 脏杯子 → **餐桌（错误容器）**：score 50→150 **（+100 分）**，chaos 16→24（+8）
  - 脏杯子 → **洗碗机（正确容器）**：score 50→200 **（+150 分）**，chaos 43→51（+8）
- **分析**：
  - 错放的**净奖励 +92 分**（+100 - 8 chaos 权重）
  - 对放的**净奖励 +142 分**
  - 对 vs 错只有 **50 分差额**！玩家如果不打开 Tab 面板看"已完成目标 ✓"，**完全没法从 score/chaos 判断自己做错了**。
- **影响（漏斗模型第 3→4 层断层）**：玩家 L1 学不到"什么是对、什么是错"，到 L2/L3 遇到真压力时完全不会正确决策，直接弃坑。
- **修复建议**：
  - 错放物品 **score 扣分（-100 起）** + chaos 大幅增加（+20 起）+ 屏幕中央弹"放错了！这个不属于这里哦～"提示
  - 正确放置 score +200、chaos 不变或减少

---

### 🏷️ P0-2｜L2 记忆过期机制体验上完全失效！玩家"凭记忆旧位置找"也能成功
- **证据**：
  - 猫扒拉钥匙事件 `se-cat-pushes-key` 已触发 ✅
  - 钥匙记忆 slot 正确变 `outdated=true` ✅
  - **但是**：钥匙从 (0, 0.3) 只移动到了 (-1, -2)，d=2.5 距离
  - 交互判定阈值 `nearbyBestDistance=2`，刚好不在可交互范围
- **分析**：
  - 玩家如果相信旧记忆走到 (0, 0.3)，只会看到"附近没东西"（很隐晦）
  - UI 上只有 **记忆槽图标变灰"已过期"**，没有强制的 toast/语音/屏幕提示
  - 真实玩家不会注意到记忆槽那个小灰色变化——他们会觉得"游戏 bug 了？钥匙消失了？"
- **影响（漏斗模型第 4 层核心机制体验断层）**：L2 的核心卖点是"识别并更新过期记忆"，但玩家根本感觉不到记忆过期带来的阻碍，白做了一整套系统。
- **修复建议**：
  - 猫移动钥匙至少 d>8（跨房间一半距离，或移到沙发底下等"藏起来"的位置）
  - 当玩家带着"过期记忆"靠近钥匙旧位置时，**弹大字提示：「你的记忆过期了！钥匙不在这儿～ 重新按 E 查找新位置吧」**
  - 或者过期记忆一旦接近旧位置，播放"喵～"音效 + 屏幕闪烁

---

### 🏷️ P0-3｜L3 难度曲线离谱：9 件衣物 + 3 格记忆槽 + 2 分钟 = 新手劝退关
- **证据**：
  - 实体数：9（3 白 + 3 深 + 2 毛巾 + 1 神秘彩条）
  - 记忆槽：3（需要频繁覆盖 6+ 次）
  - 操作距离：衣物 row 在 z=1，三个篮子 row 在 z=-2，**d=3 / 单程**
  - 总目标：4 个大目标，但没有 9 件 individual 进度条
- **分析**：
  - 纯操作耗时 = 9 × (拾取 + 移动 3 格 + 放置) ≈ 9 × 5 秒 = 45 秒
  - 记忆覆盖 / 混乱事件处理 = 至少 +40 秒
  - 试错学习空间 = 2 分钟 - 85 秒 = **只有 35 秒**
  - 新手玩家**只要犯 2 次错就超时**，失败后也不知道哪件没分完（因为没有 individual 清单）
- **影响（漏斗模型第 5 层压力 / 奖励失衡）**：完成 L2 的玩家 80% 会在 L3 超时失败，挫败感极强。
- **修复建议**（三选一）：
  - A. L3 时间改为 4 分钟（翻倍）
  - B. L3 衣物缩减到 6 件（每类 2 件）
  - C. 增加"已分类衣物高亮 + 未分类闪烁"的视觉提示

### 🏷️ P1-1｜所有操作反馈过于隐晦，玩家 UI 接收不到"我刚刚做对/做错"的信号
- **证据**：
  - L3 白衣服放错深篮：`placeIntoContainer 返回 success=false`，score -50，chaos +20
  - 但 DOM / UI 上**没有任何 toast / pop / 语音 / 屏幕震动**来强化这个信号
  - 返回的 reason 只有内部错误文案："容器不接受 white-clothes 类别的物体"（玩家根本看不到）
  - L1 放错后 HUD 的 score 变化只有 +100，玩家不会去算数字差的
- **分析**：
  - 当前所有反馈都停留在"状态变量变了"，但没有"呈现给玩家的视觉表现"
  - 游戏感 ≈ 状态机模拟，不像一个游戏
- **修复建议**：
  - 正确放置：播放清脆 SFX + 屏幕四角绿光闪烁 + "+200 ✓"飘字
  - 错误放置：播放低沉/警告 SFX + 屏幕四角红光闪烁 + "-100 ✗ 放错了！"飘字
  - 记忆过期：记忆槽震动 + 灰色 + 过期时音效 + 屏幕提示
  - 任务阶段切换：右上角 objective 条用"滑入"动画，而不是静默替换

### 🏷️ P1-2｜L2 跨房间切换后"暂停 / probing 阶段残留"偶现，导致交互全拒绝
- **证据**：
  - L2 bedroom→living transition 后，`placeIntoContainer / releaseHeldEntity` 返回 reason = **"请先开始任务"**
  - `getPhase() = probing`（正常应该是 `playing`）
- **分析**：可能是 transition 时某些事件回调错误地设置了 phase，或者 startPlaying 只在 briefing→playing 时调用过一次
- **影响**：如果真实玩家遇到这个 bug，会以为"游戏卡死了"，直接刷新或流失
- **修复建议**：
  - transitionToRoom 后做断言：如果 phase 不是 playing 就自动恢复
  - 增加 HUD debug 小灯（DEV 模式）显示当前 phase

---

### 🏷️ P1-3｜正确放置也会加 chaos（+8）！数值设计自相矛盾
- **证据**：L1 脏杯子放洗碗机（正确）→ chaos 43→51 **+8**
- **分析**：chaos 的语义是"混乱程度"——玩家把东西放回正确位置应该是**降低 chaos**，结果任何放置动作都加 chaos
- **影响**：玩家看到自己"越整理混乱值越高"，完全搞不懂规则，丧失信任感
- **修复建议**：
  - 正确放置 → chaos -15~-25
  - 错放/错误交互 → chaos +20~40
  - 时间自然流失 → chaos 缓慢增长（+0.5/秒），让混乱值"越拖延越乱"

---

### 🏷️ P2-1｜L1 结算 HUD 显示"混乱值 93%"和"房间状态：已清理"并存，互相矛盾
- **证据**：任务完成时 bodyText 有 `"混乱值 93% 3/3 房间状态 已清理"`
- **影响**：微小但令人困惑——玩家会想"我明明清理完了为什么混乱值还这么高？"
- **修复建议**：关卡完成时强制 chaos = 0%，或结算面板不显示实时 chaos 而是显示"最高混乱值 / 最终混乱值"对比

---

### 🏷️ P2-2｜"按 Tab 展开完整目标"这个主信息入口不明显
- **证据**：Tab 按钮是右上角极小的文字按钮，新手不会主动按
- **分析**：真实用户的默认行为是"盯着屏幕中间玩"，不会去角落找按钮。当前完整目标清单是判断对错的唯一方式，入口太隐
- **修复建议**：L1/L2 开场 briefing 结束后 3 秒自动弹出完整目标面板 2 秒后折叠，或给 HUD 的"目标进度 0/7"加点击展开能力

---

### 🏷️ P2-3｜L3 没有 9 件衣物 individual 清单，玩家不知道哪件漏了
- **证据**：L3 目标只有 4 条大类（白/深/毛巾 + 神秘彩条），没有 9 件明细
- **影响**：超时失败时玩家只会看到"白色衣物 0/3 完成"，但不知道是哪 3 件白色衣服、哪件没分
- **修复建议**：Tab 展开完整目标后，每个大类下列出具体物品（已完成的打勾、未完成的显示名）

## ✅ 正常流程的闪光点（值得保持）

1. **L1 引导式阶段推进非常优秀**：从 `stage-observe-table` → `stage-sort-cup-tissue` → `stage-finalize-fork`，每步都有 objective 提示，玩家知道"现在该做什么"
2. **L2 briefing 超清晰**：直接列出 7 个子任务 + 每件物品所在位置/容器 + 猫事件提示
3. **结算页 🧠 记忆表现面板是差异化亮点**：保存次数/有效/过期/效率/策略评价，让玩家"复盘自己怎么玩的"，这是其他游戏少见的
4. **记忆槽锁定/丢弃功能 UI 全**（虽然 L1 根本用不到，但有就好）
