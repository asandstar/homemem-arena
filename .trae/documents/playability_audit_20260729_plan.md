## 二、审计维度框架

按"漏斗模型"分 6 个维度评估，每个维度 0-5 分（0=无法忍受/走不下去，5=丝滑愉快/想继续玩），同时记录具体问题证据。

| 维度 | 评估重点 |
|------|---------|
| **A. 上手门槛 (Onboarding)** | 新玩家能否在 30 秒内理解"我该做什么、怎么操作"？是否需要猜？ |
| **B. 操作反馈 (Control & Feedback)** | WASD/鼠标/按键是否有反应？拾取/放置/保存记忆是否有视觉+音效双反馈？ |
| **C. 目标清晰度 (Goal Clarity)** | 每个时刻玩家是否知道下一步做什么？迷路/困惑时长占比？ |
| **D. 压力与奖励循环 (Stress & Reward)** | 混乱值、时间限制是否真的产生压力？每次正确动作是否有奖励感？记忆系统真的有用吗？ |
| **E. 事件与叙事 (Events & Story)** | 脚本事件是否给人惊喜/困扰？是否推动玩家建立"房子会捣乱"的认知？ |
| **F. 完整体验收尾 (Completion Flow)** | 完成关卡→探针→结果页是否顺畅？结果页是否有成就感+重玩动力？ |

### 3.1 Level 1：初次整理（task-clean-table）—— 教学关
**定位**：应当让新玩家在 3-5 分钟内轻松通关，建立核心循环信心。  
**目标数**：3 个 / 时间 180s / 场景：餐厅 1 间房（新手友好，不需要跨房间）

#### 操作步骤
| 步骤 | 操作 | 观察点 |
|------|------|--------|
| 1. 首页 → 任务页 | 点"任务" → 点"开始挑战"进入 L1 | 任务页是否正确显示：初次整理可玩，后两关"完成前一关解锁" |
| 2. 进入 Briefing | 读 briefing 文案 + 操作提示 | ① 30 秒内能理解目标吗？② 操作提示是否真的覆盖所需按键？③ 是否出现"开始任务"按钮？ |
| 3. 点"开始任务" | 初始化音频 + 进入 3D 场景 | ① 画面是否立刻出现？② 能否看到餐厅 3D 环境？③ 杯子/盘子/遥控器是否都在视野中？ |
| 4. 尝试移动（WASD 10 秒）| e2eApi.teleport / pressKey | ① W/S/A/D 方向是否和直觉一致？② 是否撞墙/穿墙？③ 视角是否卡顿/抖动？ |
| 5. 尝试鼠标转视角 | drag 模拟 | 是否能自由环顾四周？鼠标锁定是否正常？ |
| 6. 尝试第一个交互（走近最近的杯子）| teleport + press F pickup | ① 是否能正确 pickup？② 是否有视觉反馈（持有物显示）？③ 是否有 pick 音效？ |
| 7. 尝试放错地方 + 放对地方 | 放地面（错） vs 放洗碗机/水槽（对）| ① 错放有无惩罚提示？② 对放有无成功音效+反馈？③ 记忆槽是否有变化？ |
| 8. 保存记忆测试 | 走近物体 + press E | ① 记忆卡片是否出现？② 卡片内容能看懂吗？③ 有 memory_save 音效吗？ |
| 9. 尝试完成所有 3 个目标 | 完整操作流 | ① 能在 180s 内完成吗？② 有没有任何卡顿或不知道下一步的时刻？③ 事件是否触发？ |
| 10. 完成 → 探针页 → 结果页 | | ① 跳转是否顺畅？② 探针题能看懂吗？③ 结果页星级、评分、重玩按钮是否正常？ |

#### 本关必记具体数据
- 从进入 briefing 到"真正理解要做什么"花了多少秒
- 总共出现了几次"不知道按什么键"的时刻
- 是否有 console.error / pageerror / 失败请求
- 实际通关时长（秒）

### 3.2 Level 2：出门大作战（task-leave-home）—— 核心关
**定位**：多房间探索 + 跨房间导航 + 容器交互 + 捣乱事件（猫咪、手机）。这是体验"记忆系统价值"的主关卡。  
**目标数**：7 个 / 时间 180s / 场景：客厅 ↔ 卧室 ↔ 玄关 三间

#### 操作步骤
| 步骤 | 操作 | 观察点 |
|------|------|--------|
| 1. L1 结果页 → 返回任务页 | 点"重玩/返回" → 选 L2 | L2 是否正确解锁？ |
| 2. 读 L2 briefing | 读文案和目标 | ① 7 个目标是否有压迫感？② 关键物品（钥匙/手机/雨伞）的位置提示够不够？③"从床头柜抽屉里拿手机"是否有提示？ |
| 3. 进入场景 → 初始位置 | 客厅中心 | 初始视野是否能看到至少 1 个关键物品？ |
| 4. 第一次跨房间：客厅→卧室 | 走向卧室门洞 | ① 绿色发光门框 + 房间名标签 + 地面箭头是否可见？② 玩家需要几秒才发现"要过门"？③ 过门后小地图房间切换是否正确？ |
| 5. 容器交互：床头柜抽屉 | 走近 + F 打开 + F 拿手机 | ① 有没有"这是可以打开的"视觉提示？② 打开动画？③ 抽屉关闭时手机是否真的不可见？④ 打开后手机是否正确显示？ |
| 6. 第二次跨房间：卧室→客厅→玄关 | 连续走 2 个门 | ① 小地图红点位置是否一致？② 来回穿越是否都可以？③ 是否被空气墙卡？ |
| 7. 雨伞位置确认 | 在玄关找到雨伞 | 雨伞模型是否醒目？（红色高饱和） |
| 8. 保存 3 个关键物品记忆 | E 键 3 次 | 记忆槽 3 个满了之后，再 E 会怎样？（报错/覆盖/忽略）→ 是否符合玩家预期？ |
| 9. 触发脚本事件：猫推钥匙 + 手机响铃 | 等行为触发或 step 触发 | ① 事件发生时是否有**视觉**冲击（脚印/波纹）？② 是否有**音效**？③ 是否真的改变了钥匙位置？④ 旧记忆有没有被标记过期？ |
| 10. 送 3 件物品到玄关托盘 | 完整流程 | ① 物品放置到托盘后是否视觉正确（不悬空不嵌入）？② 7 个目标是否依次打勾？③ 全部完成后是否跳转？ |
| 11. 探针 + 结果页 | | ① 探针题目是否和实际记忆对应？② 结果页是否正确分析了表现？ |

#### 本关必记具体数据
- 跨房间时发现"可以过门"的时间（秒）
- "不知道下一步做什么"的次数 + 具体环节
- 容器打开/关闭是否各 1 次都正常
- 事件触发次数 + 各事件反馈清晰度 1-5 分
- 是否出现记忆过期视觉标识
- 实际通关时长（或失败原因：超时/chaos 满）

### 3.3 Level 3：洗衣幽灵（task-laundry-sort）—— 进阶关
**定位**：单房间但多目标管理 + 记忆槽容量限制真的会成为瓶颈。  
**目标数**：4 个 / 时间 120s / 场景：洗衣房 1 间房

#### 操作步骤
| 步骤 | 操作 | 观察点 |
|------|------|--------|
| 1. L2 通关后 L3 解锁 | 进入 L3 briefing | 洗衣房的核心机制（分类衣物）是否说明白？ |
| 2. 进入场景 | 洗衣房中心 | 9 件衣服 + 3 个篮子是否都在视野中？颜色区分是否明显？ |
| 3. 记忆槽真的不够用 | 对 4+ 件衣物尝试保存记忆 | 第 4 个 E 键按下时：是否有记忆槽已满的**明确反馈**？是否强制覆盖？玩家是否理解？ |
| 4. 分类操作流：白 T→白篮 / 黑 T→深色篮 / 毛巾→毛巾篮 | 连续 9 次拾取放置 | ① 颜色对不对玩家能否一眼区分？② 连续错误放置惩罚是否让玩家感受到压力？③ 正确 combo 是否有奖励感？ |
| 5. "篮子交换"脚本事件 | 触发 | ① 只是文字提示，还是真的改变了篮子位置？② 玩家是否被坑到？③ 有没有"幽灵恶作剧"的氛围？ |
| 6. 完成或失败 | 走向结束 | ① 120s 够不够？② 混乱值有没有可能到 100？③ 失败原因是否清楚？ |
| 7. 结果页 | | 失败是否有建设性诊断？成功是否有成就感？ |

#### 本关必记具体数据
- 能否区分白衣服/深衣服/毛巾（颜色区分清晰度 1-5）
- 记忆槽满了之后玩家的反应时间（秒）
- 事件实际效果 vs 预期（文字-only / 实际交换）
- 通关或失败时间

## 六、潜在风险与应对

| 风险 | 应对 |
|------|------|
| 浏览器自动化无法真实模拟"鼠标锁定后拖动转视角" | 使用 `e2eTestApi` 提供的 `teleportTo` / `lookAt` / `pressKey` 等效操作替代，覆盖功能正确性；对于鼠标拖动本身的手感，只能静态审查代码并在报告中标注为"需人手测试" |
| 无法完整走完关卡（例如某一步卡住）| 记录卡住点作为 P0 级问题，用 `e2eTestApi.forceWin()` 或手动 setStore 状态推进到下一环节，保证后面维度仍能被评估 |
| 音频初始化需用户手势（浏览器策略）| 先 click "开始任务"按钮（模拟用户手势），再检查 `AudioManager` 状态 |
| 3D 场景视觉正确性无法通过 snapshot 100% 判断 | snapshot 检查 HUD / UI 元素，同时每关结束用 `browser_take_screenshot` 保存关键场景截图，用于后期人工复核 |
| 脚本事件基于 step 计数，自动化操作速度快导致事件触发时机不对 | 必要时在关卡中插入等待步（`wait 3s`）模拟真人停留时长 |
